# NeuralLearn (Elearn-Ai)

AI-powered adaptive learning platform with:

- **Mobile** — Expo React Native app (`src/`)
- **Web** — Vite + React (`web/`)
- **API** — Express + Prisma (`backend/`)
- **ML** — optional FastAPI risk service (`ml-service/`)
